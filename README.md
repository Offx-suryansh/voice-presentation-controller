# 🎙️ Voice Presentation Controller

Control your presentations hands-free using voice commands! **Voice Presentation Controller** is a browser-based presentation tool designed to make navigating slides easier, more convenient, and accessible.

🌐 **Live Demo:** [Open Voice Presentation Controller](https://offx-suryansh.github.io/voice-presentation-controller/)

## ✨ Features

- 🎤 **Voice Commands** — Navigate slides using supported spoken commands.
- 📂 **Presentation Upload** — Load supported presentation files through the interface.
- ⏭️ **Slide Navigation** — Move between slides without manually clicking navigation controls.
- 🖥️ **Browser-Based** — Run the application directly in a compatible web browser.
- 🎨 **Interactive Interface** — Simple controls for managing your presentation.
- 🔒 **Local Browser Storage** — Settings and preferences can be stored locally where supported.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Web Speech API
- Browser-based presentation rendering libraries

## 🚀 Getting Started

### Use the Live Website

Visit the live demo:

**https://offx-suryansh.github.io/voice-presentation-controller/**

Allow microphone access when prompted to use voice control.

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Offx-suryansh/voice-presentation-controller.git
   ```

2. Open the project folder:

   ```bash
   cd voice-presentation-controller
   ```

3. Start a local web server. For example, if Python is installed:

   ```bash
   python -m http.server 8000
   ```

4. Open `http://localhost:8000` in your browser.

> Using a local web server is recommended because browser JavaScript modules and some presentation features may not work correctly when opening `index.html` directly.

## 🎤 Voice Control

1. Open the application in a compatible browser.
2. Grant microphone permission.
3. Load a supported presentation.
4. Activate voice control using the interface.
5. Speak the commands supported by the application to navigate your slides.

Voice recognition support depends on your browser, microphone permissions, language settings, and internet connectivity.

## 🌐 Browser Compatibility

Use a modern browser with Web Speech API support. Google Chrome and Microsoft Edge are recommended starting points.
